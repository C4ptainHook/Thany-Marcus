## Critical risks

1. **Parakeet sidecar configuration on a thin VPS** — sherpa-onnx-server image may need RAM tuning. Mitigation: fall back to a Python-FastAPI wrapper if the official image won't fit.
2. **Ollama inference latency on shared CPU** — Gemma 4 E4B Q4 should land ~15–30s/call on CCX13. If too slow for demo, demo in unsafe mode (Anthropic) — same code path, different config.
3. **Electron's `desktopCapturer` API in Obsidian plugins** — Obsidian may sandbox it. Mitigation: drop screenshot capture from plugin commands, keep only "drop screenshot file onto editor."
4. **Terraform `pg` backend concurrent locking under load** — fine for single user; if dozens of concurrent provisions happen, may need local-file backend per workspace. Acceptable for thesis-evaluation portal.
5. **Obsidian's official plugin store submission** — slow review, may need iteration. Not in MVP critical path; ship via GitHub Releases for thesis.
